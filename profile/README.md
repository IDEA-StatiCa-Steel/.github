## Four Beats

1. **Name the joint.** Give the IDEA StatiCa session a short title before you edit plates or bolts.
2. **Pin the live parts.** Keep current plates, bolts, and welds on the IDEA StatiCa board and leave unused components aside.
3. **Check the plate.** Read the IDEA StatiCa summary of stress results before you change a thickness.
4. **Close the loop.** Note which plate and bolt check is tight so the next IDEA StatiCa visit does not start by hunting the joint.

## First Questions

**Does IDEA StatiCa replace the member design model?**  
No. IDEA StatiCa sits beside the frame model and the drawings you already use.

**Can two connection designers share one computer?**  
Yes. Each person keeps a separate IDEA StatiCa profile.

**Will IDEA StatiCa stay workable on an older office laptop?**  
Yes. IDEA StatiCa is meant to stay light during a normal joint check.

**What should a new user try first?**  
One small IDEA StatiCa end-plate joint today, then the same stress results again tomorrow.

## Field Note

IDEA StatiCa is easier to trust when the joint stays smaller than the frame it came from. A named session shows which connection is active, the pins show which plates and bolts you will check today, and the closing note tells the next person where the stress results are tight. That record is short on purpose: not a copy of every component, only the path back to the joint that is still open.

The same loop fits a student end plate, a client moment connection, or a computer shared by two designers. Open the last IDEA StatiCa session, confirm one plate and bolt check, and leave the governing stress easier to find than you found it. The frame model stays where it is. IDEA StatiCa only holds the joint model, the summary, and the handoff.

## One Real Pass

Pick a connection that already has a name: a beam-to-column end plate, a base plate, or a simple splice. Open it in IDEA StatiCa, keep only those plates and bolts on the board, and read one stress result you can point to. A pass is done when that result is tied to the governing plate and the unused parts are no longer in the way. IDEA StatiCa does not need a full rebuild of the frame before it is useful.

If the pass feels crowded, the joint is too wide. Drop anything that belongs to a different connection and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first plate to the last bolt, with the summary still matching the stress results on the board.
